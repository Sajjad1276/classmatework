# Database migrations

Migration environment is configured, but no business tables are created in phase zero.

After adding reviewed SQLAlchemy models:

- Create a revision: alembic -c backend/alembic.ini revision --autogenerate -m "describe change"
- Review the generated migration before applying it.
- Apply migrations: alembic -c backend/alembic.ini upgrade head

Migrations must be forward-only schema changes with a documented logical recovery plan.
Do not run autogenerated migrations against production without reviewing their data impact.
