# ClassMate Work

سامانه مستقل مدیریت فوق‌پیشرفته ClassMate؛ شامل مدیریت سازمان و مدرسه، هویت و دسترسی، ساختار آموزشی، کاربران و عضویت، گردش‌کار محتوا، تأییدها، ارتباطات Telegram، گزارش‌گیری، audit و امنیت عملیاتی.

این ریپو محل منطق مدیریتی است و از `classmate2` که فقط روی تجربه‌ی آموزشی دانش‌آموز تمرکز دارد جدا نگه داشته می‌شود.

## سند طراحی

طراحی مرجع پیش از شروع کدنویسی در [docs/SYSTEM_DESIGN_FA.md](docs/SYSTEM_DESIGN_FA.md) قرار دارد. این سند چشم‌انداز محصول، نقش‌ها، ماژول‌ها، گردش‌کارها، معماری، مدل داده، API/event contract، امنیت و فازبندی را مشخص می‌کند.

تا زمان تأیید تصمیم‌های بخش پایانی سند، featureهای اصلی پیاده‌سازی نمی‌شوند.
